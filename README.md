# 🛒 Amazon Homepage Clone

A pixel-inspired clone of the Amazon homepage built using pure HTML and CSS.

## 🚀 Features

* Responsive navigation bar
* Amazon-style search bar
* Hero section
* Product grid layout
* Footer design
* Clean flexbox layout

## 🛠 Tech Stack

* HTML5
* CSS3
* Font Awesome
